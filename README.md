# Shupai!

A browser-based grade-six mathematics rhythm practice game.

Published copy: https://kevinlin20219-cell.github.io/shupai-six/

The default theme is the colorful festival style. Settings also offer the light theme. Learning records, calendar notes and reward selections are stored locally in each browser and are not uploaded to GitHub. Data saved on a different website origin does not automatically transfer here.

This repository contains the deployable static files from Shupai v13, source revision 59a0aaaa448927d1fe2a6154a7abe5f3fce049b9. GitHub Pages publishes the main branch root.
